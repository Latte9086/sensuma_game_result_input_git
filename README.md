# 千スマ 対戦結果の報告

選手は名前を入力し、サイド・ラウンド・対戦形式と各ゲームの結果を選びます。
送信内容を確認して一度送ると、スタッフがスプレッドシートで受け取ります。

## 設定

1. 結果用のスプレッドシートを開き、「拡張機能 → Apps Script」に [gas/Code.gs](gas/Code.gs) を保存します。
2. シートを開き直し、「千スマ → このシートを保存先に設定」を実行します。
3. GASをウェブアプリとしてデプロイします。既存のデプロイを使う場合は、新しいバージョンに更新してください。実行ユーザーはシートへ書き込めるデプロイ担当者とし、アクセス範囲は参加者が使える設定にします。
4. フロントエンドのビルド環境で `VITE_GAS_URL` にデプロイの `/exec` URLを設定し、`npm ci`、`npm run build` を実行します。出力は `dist/` です。個別の端末では「送信先設定」からも指定できます。
5. Discord通知を使う場合は、Apps Scriptの「プロジェクトの設定 → スクリプト プロパティ」に `DISCORD_WEBHOOK_URL` を設定します。

## スタッフの操作

- `Matches` のサイド、ラウンド、選手、スコア、勝者で確認します。「受付済」「訂正承認済」の行を start.gg に反映し、完了後に「反映済」をチェックします。
- 各行の「ゲーム内訳を開く」から `Games` に移動できます。行を並べ替えた場合は、両シートに共通する報告IDで該当行を確認できます。
- 「訂正确認待ち」は、訂正元IDで元の行と照合します。訂正の行を選び、「千スマ」メニューから承認または却下します。すでに反映した報告の訂正を承認したら、必要に応じてスタッフが start.gg 側も訂正します。
- 「保存処理中」の行は明細の保存確認前です。選手が同じ内容で再試行すると、同じ報告IDで保存を再開します。
- Discord通知は進行用の要約を表示し、タイトルからシートを開けます。通知の結果は `Matches` の「Discord」列で確認できます。
- 既存の `Matches` と `Games` は、新しい報告の受付時に右端の管理列を追加します。状況欄が空の既存行は、従来の「反映済」欄で管理できます。旧報告の訂正はスタッフが確認して処理します。
